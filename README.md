# SaaradhiGO Web Platform 🚖

Welcome to the **SaaradhiGO Web** repository! This is the frontend interface for a next-generation mobility and ride-hailing platform. Built with a focus on a premium, interactive user experience, this application delivers a highly refined aesthetic using modern web technologies.

## ✨ Key Features

- **Interactive Dynamic Map**: An advanced map interface built using Leaflet, featuring custom, branded vehicle nodes (Bikes, Autos, Cars) reflecting real-time simulation.
- **Premium Rider Dashboard**: A richly designed dashboard integrating glassmorphism, 3D hover effects (tilt & shimmer), ambient glow tracking, and real-time status updates for users and drivers.
- **AI-Powered Incident Simulation**: A dynamic feature allowing users to input failure descriptions and have them classified in real-time through an intuitive UI.
- **Dynamic Health Reports**: Personalized user wellness reports generating real-time, dynamic imagery based on user exercise metrics and required medicine details.
- **High-End UI/UX Aesthetics**: Complete with tailored color palettes (gold shimmers, dark mode glass components), sophisticated micro-animations (Framer Motion), and modern typography.

## 🚀 Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom CSS for complex UI animations
- **UI Components**: [Radix UI](https://www.radix-ui.com/) mixed with [Framer Motion](https://motion.dev/) for seamless interactions, and [Material UI](https://mui.com/).
- **Mapping**: [Leaflet](https://leafletjs.com/) & `react-leaflet`
- **Data Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

Follow these steps to run the application locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v16 or higher) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Suprith1215/SaaradhiGO-Web.git
   ```

2. Navigate to the project directory:
   ```bash
   cd SaaradhiGO-Web
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the App Locally

To start the local Vite development server:

```bash
npm run dev
```

Your app will be automatically served, typically on `http://localhost:5173`. 

### Building for Production

To create an optimized production build:

```bash
npm run build
```

The bundled assets will be generated in the `dist` directory, ready to be deployed to your hosting provider.
